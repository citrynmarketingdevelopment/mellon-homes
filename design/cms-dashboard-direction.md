# Mellon workspace and property browser

Applied ui-ux-pro-max: design-system search (real estate/property management, modern, pink/green, density 8), followed by accessibility/loading/navigation guidance.

The generated monitoring/luxury suggestions were adapted to Mellon’s established brand: local Bricolage Grotesque and DM Sans, forest green, soft pink, warm white, and restrained mint. No new remote fonts or runtime design dependencies.

- Desktop: persistent sidebar, compact content header, Overview with real counts, separate Listings manager and New listing editor, Account screen.
- Mobile: four labeled bottom tabs, safe-area padding, single-column content, property rows with 44px controls. No horizontal table scrolling.
- Manager: search, publication/featured filters, price sorting, ten rows per page, persistent quick featured/status changes, edit links, native modal confirmation before deletion.
- Public collection: published-only records, featured ordering, availability filters, search by title/address/city/ZIP, price sorting, compact mobile photo cards, explicit empty/error states.
- Interaction: server authorization and revisions for mutations, loading/disabled feedback, visible keyboard focus, Escape and focus restoration for the delete modal, reduced-motion support.
- Retained: existing homepage hero, brand palette, and actual listing content.
